# Canadian Equity Market Access for a Python Algo Developer (TSX, TSXV, CSE, Cboe Canada/NEO): brokers, paper trading, data, regulation, microstructure

Research date: 2026-10-25. Where a page was fetched directly on that date I say "fetched 2026-10-25". Where I only saw a search-result summary of a page (the page itself was blocked, down, or not opened) I say so. tsx.com and tmx.com were serving an outage notice ("websites currently unavailable") when I tried to fetch them, so TSX/TMX facts below come from search-result snippets of those pages and are flagged.

## 1. Which brokers offer a public trading API for TSX/TSXV/CSE listings plus paper/demo (the CIRO automated-order restriction is the key finding)

### Takeaway
For a Canadian-resident retail client, no mainstream broker offers a self-service programmatic order API for Canadian-listed securities. IBKR Canada explicitly blocks API orders on Canadian exchanges (citing a CIRO rule), and the Questrade API only lets partner developers place orders. IBKR Canada's API still works for US-listed securities, and Questrade now offers human-approved AI order drafting (MCP) and a no-code rules engine (Flows) instead of an order API.

### Cited Findings

**Interactive Brokers (IBKR Canada)**
- IBKR's own docs state: "Interactive Brokers Canada Inc. (IBC) does not allow users to use your own trading application to electronically submit order for products traded on a Canadian exchange or other marketplace through API, which would include Third Party Integrations." The decision followed communications with CIRO, which implemented IIROC Dealer Member Rule 3200 A.1.(b)(i), "which prohibits CIRO registrants, including IBC, from allowing its clients to use their own automated order systems to generated orders." The restriction also applies to TradingView, NinjaTrader and similar tools because they use an API connection. — [IBKR Web API docs](https://www.interactivebrokers.com/docs/web-api/v1/requirements-limitations/canadian-residents-restricted-from-programmatically-trading-canadian-products) (fetched 2026-10-25). The same notice appears under "Canadian Residents Restricted From Programmatically Trading Canadian Products" in the [TWS API Limitations page](https://www.interactivebrokers.com/docs/tws-api/doc/notes-limitations/tws-api-limitations) (fetched 2026-10-25).
- Anecdotal (QuantConnect forum, undated thread): a user with an Alberta IB Canada account got "Order rejected - reason: API/CTCI orders for canadian stocks are not allowed" when ordering VCN on the TSX, while AAPL on Nasdaq went through via the API. IBKR client services said "Canadian clients cannot place API orders for Canadian securities" and that third parties must abide by the same regulation. Another poster claimed a live algo through IB Canada (Ontario) ran about 18 months without issue (probably US securities; not stated). One poster said paper trading in CAD did not hit the problem, but the post is ambiguous about what was traded. The forum suggestion was to open an IB USA account (not an IBKR-endorsed route). — [QuantConnect forum thread 7303](https://www.quantconnect.com/forum/discussion/7303)
- IBKR's Canada commission page says there are "no account minimums"; tiered commission is CAD 0.008/share up to 300,000 shares/month (CAD 0.005, 0.004, 0.003 at higher tiers), fixed is CAD 0.01/share, minimum CAD 1.00 per order, maximum 0.5% of trade value; clearing fees CAD 0.00017/share capped at CAD 2.00/order (TSXV CAD 0.00010/share). — [IBKR Canada commissions](https://www.interactivebrokers.ca/en/pricing/commissions-stocks.php) (fetched 2026-10-25)
- IBKR paper accounts require an existing, funded live account; "Only existing clients can request a Paper Trading Account"; paper accounts cannot be converted to live. — [IBKR Client Portal guide, last updated Oct 22, 2026](https://www.ibkrguides.com/clientportal/aboutpapertradingaccounts.htm)
- API surface: TWS/IB Gateway default ports are 7497 (TWS paper), 7496 (TWS live), 4002 (Gateway paper), 4001 (Gateway live). — [NautilusTrader IB docs](https://nautilustrader.io/docs/latest/integrations/interactive_brokers/)
- Python wrapper: ib_async (successor to ib_insync) is on PyPI at v2.1.0 (released 2025-12-08), requires Python >=3.10, repo `ib-api-reloaded/ib_async`. — [PyPI JSON metadata](https://pypi.org/pypi/ib_async/json) (fetched 2026-10-25). The first ib_async release was "functionally equivalent to the final version of ib_insync 0.9.86"; ib_insync's author Ewald de Wit died in early 2024 and the project moved under new maintainers (Matt Stancliff per README). — [ib_async on PyPI / search summary](https://pypi.org/project/ib_async), [GitHub mirror README](https://github.com/ClimberMel/ib_async)
- IBKR API pacing: historical-data pacing violations occur on identical requests within 15 seconds, six or more requests for the same contract/exchange/tick type within 2 seconds, or more than 60 requests in 10 minutes (BID_ASK counted twice). The general limit is max market-data lines / 2 requests per second (50/s at the default 100 lines). — [IBKR pacing docs (search-result summary; page not opened directly)](https://www.interactivebrokers.com/docs/tws-api/doc/pacing-limitations/introduction.md)

**Questrade**
- "The Questrade API enables you to develop live or practice applications that can access your account data and retrieve market data. If you are a Questrade partner developer, you can also use the API to place trades." Partnership requires emailing Questrade with platform details. Personal apps use a manual refresh token redeemed at login.questrade.com (practice: practicelogin.questrade.com); the sample access token has `expires_in: 300`. — [Questrade API getting started](https://www.questrade.com/api/documentation/getting-started) (fetched 2026-10-25)
- "Executing trades using the API is available to Questrade partner developers only. If you're a customer with Questrade, you can access account and market data but you cannot execute trades using the API." The API is free; users of a partner app pay normal commissions. — [Questrade API home](https://www.questrade.com/api/home) (fetched 2026-10-25)
- Order endpoints exist (POST accounts/:id/orders, /impact, /bracket, /strategy, DELETE) but are partner-scoped. — [Questrade POST orders doc](https://www.questrade.com/api/documentation/rest-operations/order-calls/accounts-id-orders)
- Rate limits: account calls 30/sec and 30,000/hour; market-data calls 20/sec and 15,000/hour. — [Questrade rate limiting](https://www.questrade.com/api/documentation/rate-limiting)
- Candles endpoint returns at most 2,000 candlesticks per response. — [Questrade candles doc](https://www.questrade.com/api/documentation/rest-operations/market-calls/markets-candles-id)
- Quotes: a real-time data package is needed for real-time quotes; otherwise calls are snap quotes with a per-market limit and "the response will return delayed data" once exceeded. — [Questrade quotes doc](https://www.questrade.com/api/documentation/rest-operations/market-calls/markets-quotes-id)
- Streaming is L1 only (plus order/execution notifications); "If you use L1 Streaming in Trading API, then your market data will freeze in any other IQ Platform that you are using simultaneously." — [Questrade streaming doc](https://www.questrade.com/api/documentation/streaming)
- The downloadable C++/C# API packages on the getting-started page are dated Dec 18, 2015 (v1.1.0). — [Questrade API getting started](https://www.questrade.com/api/documentation/getting-started)
- The end-user licence agreement reportedly says users will not send orders "on a pre-determined or automated basis" using a partner application except where Questrade allows. — [Questrade API access agreement (search-result summary; not opened directly)](https://www.questrade.com/disclosure/legal-notice-and-disclosures/api-access-agreement)
- Questrade MCP (AI connector): read balances, positions, orders, quotes, historical prices and option chains; can draft orders only. "You approve every trade yourself. The AI agent cannot place, change, or cancel an order on its own." Needs Questrade app v2.0.0+ with Push Approval; trading permission is a separate opt-in; order/activity history covers the last 90 days. Server: `https://mcp.questrade.com/v1/brokerage/mcp`. The page (fetched 2026-10-25) says support is now available for Claude, ChatGPT, Cursor, VS Code and Codex CLI; news from July 2026 said only Claude and Claude Code at beta launch. — [Questrade MCP guide](https://www.questrade.com/learning/using-questrade/connect-your-questrade-account-to-ai); [press coverage of the July 2026 beta](https://www.wealthprofessional.ca/news/industry-news/questrade-claims-first-in-canada-ai-account-access-as-brokerage-rivalry-intensifies/393150)
- Questrade Flows (announced July 30, 2026): no-code "if this, then that" rules in Questrade Pro/app that place trades and alerts; stocks, ETFs, single-leg options; $250,000 per-order cap; up to 50 Flows (max 20 order-placing); scans every 1-2 seconds; orders in regular, pre-market, after-hours and overnight sessions for eligible stocks/ETFs; free apart from commissions; you must confirm the logic before activation. Flows terms say orders remain subject to Questrade's pre-trade controls and CIRO requirements. — [Questrade Flows guide](https://www.questrade.com/learning/using-questrade/automate-your-trading-strategy-with-flows-in-questrade-pro) (fetched 2026-10-25); [launch press release](https://www.bnnbloomberg.ca/press-releases/2026/07/30/questrade-leads-new-age-of-financial-services-in-canada-unleashing-agentic-finance-0-options-and-more/) (search-result summary); an older/other Questrade page was reported to cite a $10,000 order cap, so the figure may differ by page version.
- Questrade market data for retail: the free package includes real-time L1 streaming for TSX and TSXV (shown on Edge platforms) and free snap quotes; Expanded package $9.95/month; Advanced (Level 2, adds depth) $44.95 USD/month. — [Questrade real-time streaming plans](https://www.questrade.com/learning/using-questrade/real-time-streaming-plans) (fetched 2026-10-25)

### Inferences
- Because the CIRO rule targets "order execution only" dealers' clients using their own automated order systems, any Canadian-regulated discount brokerage (IBKR Canada, Questrade, Qtrade, bank brokerages) is likely constrained the same way for Canadian-listed securities. Questrade's partner-only gate and its human-approval MCP design are consistent with this, but Questrade does not state CIRO as the reason.
- Realistic Python-programmable paths for a Canadian resident today: (a) IBKR Canada API for US-listed securities (including US listings of Canadian interlisted names), (b) signals-only for Canadian listings with manual or human-approved order entry (Questrade MCP approval flow, or typing orders in TWS), (c) Questrade Flows for simple rule-based execution (cannot run a custom ML model; no Python hook was documented).
- Moomoo's Canada paper app is the only item found offering a Canadian-market paper account in a retail app, but it is not programmable through OpenAPI.
- Alpaca Canada is unlikely to help with TSX in the near term: even if approved around November 2026, nothing indicates TSX support.

### Gaps
- I could not confirm whether an IBKR paper account (DU...) accepts API orders for TSX symbols from a Canadian-resident login. The forum evidence is ambiguous. It should be tested directly (qualify a TSX contract, send an order to the paper account) before designing around it.
- Questrade partner-program criteria, timelines and costs are not published; whether a solo developer can be accepted is unknown.
- I did not confirm whether non-resident status, a different IBKR entity, or a CIRO-recognized direct-electronic-access arrangement would be available to an individual, nor what rule text applies after the CIRO rulebook consolidation (see section 4).
- Qtrade, CIBC and National Bank were only covered by a general search; absence of an API is "not found", not proven.
- The Tradier and tastytrade statements come from secondary consumer sites; Webull Canada's API eligibility is unconfirmed.

## 2. How realistic is each broker's paper trading engine (IBKR focus), including known differences from live

### Takeaway
IBKR's paper engine fills against real top-of-book prices but IBKR itself says it is a simulator that plays the exchange's role: no deep-book/queue modelling, simulated stops, rejected partial remainders on market orders, and no slippage, impact or fee realism. Paper data is delayed unless live data subscriptions are shared, with a same-device restriction.

### Cited Findings
- IBKR: "Trades entered into a paper trading account will not actually execute on any exchange or settle at a clearing house. However, the simulated price of the executions will be determined by real market prices and sizes." Trading permissions, market-data subscriptions, base currency and other configuration "are the same as specified for your regular account." Starts with USD 1,000,000; reset allowed up to five times the production account value (request before 4pm ET); paper accounts "may be closed due to inactivity". — [IBKR Client Portal: About Paper Trading Accounts](https://www.ibkrguides.com/clientportal/aboutpapertradingaccounts.htm) (last updated Oct 22, 2026)
- Documented limitations: no VWAP, Auction, RFQ or Pegged-to-Market order types; "Fills are simulated from the top of the book; no deep book access"; limited combo trading; "Stops and other complex order types are always simulated in paper trading, which may result in slightly different behavior from a production account"; "The trade simulator will reject the remainder of any exchange-directed market order that partially executes... Market orders received while there is no quote on the opposite side will be held until the first partial fill." — [IBKR Client Portal: About Paper Trading Accounts](https://www.ibkrguides.com/clientportal/aboutpapertradingaccounts.htm)
- IBKR knowledge base: a paper account is "a simulated account trading in a simulated market... We are simulating not only the trader's functionality and the market, but also the role of the exchange... While these fills may or may not be within the bounds of the live market at the time, in no way is it indicative of what would happen in the real market." "There is no way to exactly replicate live markets." — [IBKR KB article 252](https://ibkb.interactivebrokers.com/article/252) (last updated Nov 11, 2024)
- IBKR Campus: paper trading "simulates the order filling based on the real-time quotes" and does not account for market impact, price slippage, market microstructure, price improvements, regulatory fees, or dividends. — [IBKR Campus: From Back Test to Paper Trading](https://www.interactivebrokers.com/campus/?p=155866) (fetched 2026-10-25)
- The TWS API docs warn "the Paper Trading Environment relies on more simulated technologies than the Live trading environment. As a result, certain behavior such as order execution may vary" and that the environment "has inherent limitations." — [TWS API Limitations](https://www.interactivebrokers.com/docs/tws-api/doc/notes-limitations/tws-api-limitations)
- Market data in paper (IBKR knowledge base, search-result summary): the paper user has no subscriptions of its own; it can be set to share the live user's subscriptions, but if both sessions run at once they must be on the same device or the paper session gets no data; if not sharing, the paper user receives delayed data where available. Delayed data via API is Level 1 only, not available for tick-by-tick or market depth (an IBKR Campus answer per the same summary). — [IBKR KB article 1719](https://ibkb.interactivebrokers.com/article/1719); [IBKR delayed-data table](https://www.interactivebrokers.com/en/trading/papertrader-delayed-data.php)
- IBKR Canada delayed-data table lists Toronto Stock Exchange (TSE) and TSX Venture (VENTURE) as 15 minutes delayed. — [IBKR Canada market data pricing](https://www.interactivebrokers.ca/en/pricing/market-data-pricing.php) (fetched 2026-10-25)
- QuantConnect: IBKR FIX integration is "not supported for IB simulated accounts, which start with the letters 'DU'". — [QuantConnect IB brokerage docs](https://www.quantconnect.com/docs/v2/cloud-platform/live-trading/brokerages/interactive-brokers.md) (fetched 2026-10-25)
- Moomoo paper: orders match when priced through best bid/ask; fees are simulated with a Canadian broker-dealer default; the system "may not necessarily be consistent with the real stock market"; supports dividends/bonus shares but not IPO subscription. — [Moomoo CA paper trading rules](https://www.moomoo.com/ca/support/topic10_102)
- Webull: a sandbox API application is approved automatically within minutes (Australian developer-site description); a July 2026 Webull US press release says paper trading expanded to crypto, futures, bonds and event contracts and is reachable via API. US-market only; Canadian eligibility unconfirmed. — [Webull developer docs](https://developer.webull.com/apis/docs/authentication/IndividualApplicationAPI/) (search-result summary)
- Questrade: a "practice" API server (practicelogin.questrade.com) is referenced in the docs; I found no documentation of how practice-account fills behave. — [Questrade API getting started](https://www.questrade.com/api/documentation/getting-started)

### Inferences
- For a short-horizon model, IBKR paper fills at displayed top-of-book are optimistic: no queue position, no market impact, no partial-fill realism beyond the market-order rule, no regulatory/exchange fees (a few hundredths of a cent per share, but material to a high-turnover strategy), and simulated stops. Treat paper results as a pipeline/plumbing test and a latency/data-feed sanity check, not a P&L estimate.
- Because the IBKR paper account inherits your live data entitlements, paying for TSX L1 on the live user and sharing it is the cleanest way to get live (not 15-min delayed) Canadian quotes in paper. The same-device restriction means you cannot run live TWS on a laptop and the paper bot on a server unless you add a second user (extra data fees, per IBKR's summary).
- For fidelity, add your own fill model on top of the paper engine's output (spread crossing, per-share fees, partial fills by volume participation) and log both.

### Gaps
- No source found documenting Questrade practice-account fill behaviour, or whether Moomoo's paper engine rejects/partially fills.
- No independent (non-IBKR) quantitative study of IBKR paper-vs-live fill differences was found.
- I did not confirm whether IBKR's paper engine fills TSX orders differently from US ones (e.g., Canadian odd lots, auction sessions).

## 3. Real-time and historical Canadian market data: sources, prices, depth, survivorship

### Takeaway
Cheapest live TSX data for a retail Canadian is an IBKR subscription (TSX L1 CAD 9/month non-pro, L2 about USD 14) or Questrade's free L1 package; most US-centric vendors (Databento, Massive/Polygon, FirstRate, Kibot) do not cover Canada. For daily history, EODHD (about $20-30/month) and Norgate (CAD 630/year for delisted stocks back to 1990) are the affordable options; tick and order-book history comes only from the exchanges (for example Cboe Canada PITCH at CAD 1,000/month per daily file) or enterprise vendors.

## 4. Canadian regulatory considerations for retail algorithmic trading

### Takeaway
The binding constraint is CIRO's rule against order-execution-only clients using their own automated order systems (the reason IBKR Canada blocks API orders on Canadian marketplaces). Canada has no US-style PDT rule for Canadian-listed trading, short selling needs a margin account and a locate, and frequent trading is likely taxed as business income, with the superficial-loss rule an automatic trap for high-turnover strategies.

### Cited Findings
- CIRO guidance says Dealer Member Rule 3200 clarifies that a dealer offering an order-execution service must not allow clients to use their own automated order system to generate or send orders; "automated order system" takes its meaning from National Instrument 23-103 (Electronic Trading and Direct Electronic Access to Marketplaces). IDPC Rules also provide that an order-execution client must use an automated order system provided by the dealer and give CIRO authority to set a threshold on orders manually sent. Earlier proposals to restrict OES to retail customers and require annual checks for third-party automated systems "have not been brought forward." — [CIRO: third-party electronic access provisions (search-result summary; direct fetch blocked)](https://www.ciro.ca/newsroom/publications/provisions-respecting-third-party-electronic-access-marketplaces), [CIRO OEO guidance](https://www.ciro.ca/newsroom/publications/guidance-respecting-order-execution-only-accounts-form-third-party-electronic-access-marketplaces-0)
- IBKR Canada cites DMR 3200 A.1.(b)(i) as the basis of its API block (see section 1). — [IBKR Web API docs](https://www.interactivebrokers.com/docs/web-api/v1/requirements-limitations/canadian-residents-restricted-from-programmatically-trading-canadian-products)
- I could not retrieve the current consolidated IDPC rule text; the CIRO rulebook was consolidated into "Dealer and Consolidated Rules" in 2023, so the rule number may have changed. — [CIRO rule consolidation (OSC copy)](https://www.osc.ca/sites/default/files/2023-10/ciro_20231020_rule-consolidation.pdf)
- Pattern day trading: a broker-education site says Canada has no domestic USD 25,000 PDT rule, but US rules can reach Canadians trading US securities through brokers that clear in the US; IBKR Canada's margin page states the NYSE/NASD day-trading limits on US stocks apply to Canadians. — [DayTrading.com Canada](https://www.daytrading.com/rules/canada), [IBKR Canada stock margin](https://www.interactivebrokers.ca/html/retailAccount/stockMarginReq.html) (search-result summaries). A Wikipedia summary says FINRA replaced the PDT rule with intraday margin standards, SEC-approved, effective June 4, 2026, with brokers allowed to phase in until October 20, 2027 (single secondary source; verify). — [Wikipedia: Pattern day trader](https://en.wikipedia.org/wiki/Pattern_day_trader)
- Short selling: Questrade says shorting is available only in margin accounts and is subject to borrow availability and margin thresholds, with eligibility "aligned with CIRO requirements"; a Motley Fool Canada article says brokers must locate stock and small/thin names may be hard-to-borrow or unavailable. Review sites rank IBKR Canada best for short selling (opinion). — [Questrade margin guide](https://www.questrade.com/learning/buying-on-margin), [Motley Fool Canada](https://www.fool.ca/investing/how-does-shorting-a-stock-work/)
- Tax, business income vs capital: "There's no bright-line test"; CRA looks at conduct and intentions and factors such as frequency, short holding periods, time spent, whether trading is a business, financing on margin, speculative securities; day traders' gains and losses are generally business income (100% taxable, 100% deductible, reported on T2125) rather than capital (50% taxable). — [TaxTips.ca](https://www.taxtips.ca/personaltax/investing/taxtreatment/are-your-investment-gains-and-losses-capital-or-income.htm), [Fidelity Canada](https://www.fidelity.ca/content/fidca/en_CA/insights/articles/day-trading-in-a-tfsa.html), [Advisor.ca](https://www.advisor.ca/tax/tax-news/watch-for-this-tfsa-trading-pitfall/)
- CRA has taken the position that extensive trading in a TFSA can mean the TFSA is carrying on a business, making gains taxable. — [Advisor.ca: TFSA trading pitfall](https://www.advisor.ca/tax/tax-news/watch-for-this-tfsa-trading-pitfall/)
- Superficial loss rule: a loss is denied if you (or an affiliated person such as a spouse or controlled corporation) acquire identical property in the 61-day window (30 days before, the day of, and 30 days after the sale settlement) and still hold it at the end; the denied loss is generally added to the adjusted cost base of the replacement; timing runs on settlement dates, and Canada's move to T+1 shifts the arithmetic. — [RBC Wealth Management: superficial loss rules](https://ca.rbcwealthmanagement.com/documents/1435520/3126711/NAV0072+-+Superficial+loss+rules.pdf/1b4aef6b-ae5f-4125-af6e-e106b1563fee), [Advisor.ca](https://advisor.ca/tax/tax-news/tax-loss-selling-superficial-loss-and-identical-property-rules/)

### Inferences
- A fully automated retail loop for TSX/TSXV/CSE names through a CIRO-regulated retail dealer looks non-compliant by design. The workable compliant variants are human-in-the-loop or broker-supplied automation (Questrade Flows, MCP approvals). Confirm with the broker's compliance team and a securities lawyer before relying on any workaround.
- A model that trades frequently (especially on margin, short holding periods) should assume business-income treatment, so budget for full taxation of gains, full deductibility of losses and bookkeeping; the superficial-loss rule can trip a mean-reversion model that re-enters the same ticker within 30 days of realizing a loss, and the rule applies across all your accounts (and spouse's).
- The PDT question is mostly moot for TSX trading; it matters only for US-listed trading through a US-cleared account, and is in flux after the June 2026 FINRA change.

### Gaps
- No primary CRA, CIRO or Income Tax Act text retrieved (canada.ca fetch failed; CIRO pages returned 403); the tax and CIRO points rely on secondary summaries.
- Canadian-specific short-sale rules (marking, uptick-type restrictions, borrow rules) were not found.
- Whether CIRO has any 2025-2026 changes to the OES automated-order restriction was not confirmed.

## 5. Canadian market microstructure facts for simulation fidelity

### Takeaway
Canada has one dominant exchange (TSX) plus several protected marketplaces under an order-protection rule that protects all visible displayed orders. Ticks are $0.01 at or above $0.50 and $0.005 below, there are explicit pre-open, auction and extended sessions, and small-cap venues (TSXV, CSE) have heavily skewed liquidity.

### Cited Findings
- TSX sessions (per the TSX trading-hours page, search-result snippet; tsx.com was down): pre-open 7:00-9:30 ET (orders accepted, not executed); opening trade 9:30; continuous 9:30-16:00; Market on Close facility 15:50-16:00; Post Market Cancel Session 16:10-16:15; Extended Trading Session 16:15-17:00 where trades may only occur at the last sale price. — [TSX trading hours](https://tsx.com/en/trading/calendars-and-trading-hours/trading-hours). Questrade says most retail investors do not use the post-close TSX session. — [Questrade market hours](https://www.questrade.com/learning/options-active-trading/stock-market-trading-hours). EODHD lists TSXV hours as Mon-Fri 09:30-16:00 America/Toronto. — [EODHD TSXV](https://eodhd.com/exchange/V)
- Tick size: UMIR 6.1 bars order entry at increments finer than $0.01 CAD at or above $0.50 and $0.005 CAD below $0.50 (for non-US-interlisted securities); for US interlisted securities CIRO designates increments semi-annually. CIRO proposed alignment with SEC Rule 612 (Dec 2024); a June 22, 2026 bulletin sets implementation at November 1, 2027. — [CIRO proposed trading increments](https://www.ciro.ca/news-room/publications/proposed-amendments-respecting-trading-increments), [CIRO bulletin Jun 22, 2026](https://www.bcsc.bc.ca/-/media/PWS/New-Resources/Industry/Marketplaces-SROs-and-Market-Infrastructure/SROs/2026/CIRO--Rules-Bulletin--Technical--Revised-Implementation-Date-for-Amendments-Respecting-Trading-Increments-June-22-2026.pdf)
- Marketplaces and order protection: CIRO's list effective April 1, 2024 shows protected TSX (44.04% market share), Nasdaq CXC (11.11%), Omega (6.44%), Nasdaq CX2 (5.06%), plus CSE, NEO-L and TSX Venture; unprotected Alpha (7.30%, no automated trading functionality), Alpha-X and Lynx (0.36%, below threshold). Cboe Canada's share was not shown in the snippet. Canada's rule protects all visible quotes on protected marketplaces, not only the top of book as in US Reg NMS (2014 article quoting Omega's CEO). — [CIRO OPR market share threshold, Apr 1 2024](https://www.ciro.ca/news-room/publications/order-protection-rule-market-share-threshold-effective-april-1-2024) (search snippet), [Markets Media](https://www.marketsmedia.com/canada-reviews-order-protection-rule)
- TSX fees (schedule effective July 2, 2026, search snippet of the PDF): opening board-lot trades and Market on Close $0.00225/share/side with per-order caps ($20, $200 Must Be Filled, $50 other); Extended trading $0.0010/share/side; Minimum Guaranteed Fill $0.0017 (non-interlisted equities/ETFs priced $1+) and $0.0030 (interlisted); odd-lot fills $0.00025 (under $1) and $0.0005 ($1+); TSXV extended trading $0.0002/share/side. Continuous-trading active/passive rates were not in the snippet. — [TSX fee schedule PDF](https://tsx.com/en/resource/3521/tsx-trading-fee-schedule-effective-july-2-2026-en.pdf), [TSXV fee schedule](https://tsx.com/en/trading/tsx-venture-exchange/fee-schedule)
- IBKR Canada passes through exchange fees by venue (Aequitas/Cboe NEO, ALPHA, CSE, CHI-X, LYNX, MATCHNow, Nasdaq CXD, Omega, TSX/TSXV listed) in a "Canada - Third Party Fees" section; clearing CAD 0.00017/share (cap CAD 2/order). — [IBKR Canada commissions](https://www.interactivebrokers.ca/en/pricing/commissions-stocks.php)
- Liquidity: TMX reported TSX Venture December 2025 daily average volume of 261.6 million shares and C$215.3 million value (versus 156.5 million shares and C$67.1 million in December 2024); TMX noted the average TSX/TSXV issuer traded about 63% of volume on TMX marketplaces in 2024. — [TMX consolidated trading statistics, Dec 2025](https://investors.tmx.com/English/News--Events/news/news-details/2026/TMX-Group-Consolidated-Trading-Statistics---December-2025/default.aspx), [TMX POV](https://tmx.com/en/pov?id=159)
- CSE: more than 800 listed issuers and a record month of 9.3 billion shares traded in February 2021; it also runs a continuous auction market for securities listed elsewhere. — [CSE about](https://www.thecse.ca/about)
- Interlisted stocks: academic work on TSX/NYSE cross-listings finds both markets contribute to price discovery (US share averaged about 36% in an older sample), and a recent thesis finds algorithmic trading activity negatively related to price-discovery contribution for cross-listed stocks (arbitrageurs competing). Source details are from search-result summaries. — [JOIM: price discovery for cross-listed stocks](https://joim.com/price-discovery-cross-listed-stocks), [AUT thesis](https://openrepository.aut.ac.nz/items/a44a5614-01fa-40eb-ace1-d7c445afd430)
- TSX charges a higher MGF rate for interlisted names ($0.0030 vs $0.0017), showing the exchange treats them as a distinct class (see TSX fee bullet above).

### Inferences
- A faithful simulator should model: pre-open (no fills), opening and closing auctions, the 15:50 MOC window, a no-trade 16:00-16:15 gap, a limited extended session, $0.005 vs $0.01 ticks, and multi-venue routing with fees that differ by venue (maker-taker plus special pricing for interlisted names). At least four lit protected venues beyond TSX (CXC, CX2, Omega, NEO-L) matter for fill assumptions.
- TSXV and CSE small caps: skewed volume (a few heavily traded issuers dominate averages), so use per-symbol ADV and spread filters; assume wide spreads and thin books for typical names (no spread statistics found, so this is an assumption).
- Interlisted arbitrage between TSX and NYSE/Nasdaq is competitive and mostly electronic; a retail model should not expect free edge from price gaps. Trading the US leg is the only API-programmable leg for Canadian residents (section 1).

### Gaps
- Board lot sizes (100 shares etc.) and odd-lot rules were not verified from a source.
- Continuous-trading maker/taker fee rates for TSX, Nasdaq CXC/CX2, Cboe Canada, Omega, Lynx were not retrieved.
- No bid-ask spread or turnover statistics for TSXV/CSE penny stocks; no CSE volume stats for 2025.
- Cboe Canada market share and protected status were not confirmed.
- Short-sale price tests and circuit-breaker rules were not found.

## 7. Bottom line: easiest path to start with Canadian stocks today and the most realistic paper-to-live path

### Takeaway
Easiest start: open an IBKR Canada account (no minimum), subscribe to TSX L1 (CAD 9/month), buy Norgate Platinum (CAD 630/year) or EODHD ($19.99-29.99/month) for history, and build/paper-test the model against IBKR's paper account. The hard part is the live step: for Canadian-listed names a Canadian retail resident cannot send orders from their own program through IBKR Canada (blocked by IBKR citing CIRO) or Questrade (API orders limited to partners), so live deployment needs human-in-the-loop execution, broker-provided automation, or trading US-listed/interlisted tickers via the API.

### Cited Findings
- Fully funded IBKR account is a prerequisite for paper trading; paper inherits live market-data entitlements and uses real prices/sizes with top-of-book fills (section 2). — [IBKR paper trading guide](https://www.ibkrguides.com/clientportal/aboutpapertradingaccounts.htm)
- IBKR TSX L1 costs CAD 9/month (non-pro, Canadian residents), TSXV CAD 9, TSX L2 about USD 14, CSE USD 2.50, NEO USD 1.00; 100 free lines by default. — [IBKR Canada market data pricing](https://www.interactivebrokers.ca/en/pricing/market-data-pricing.php)
- Norgate Platinum Canada CAD 630/12 months includes delisted securities and historical constituents back to 1990. — [Norgate packages](https://norgatedata.com/stockmarketpackages.php)
- IBKR Canada blocks API orders in Canadian-listed products; Questrade API orders are partner-only; Questrade offers human-approved MCP drafting and Flows rules; Moomoo OpenAPI has no Canadian market; Alpaca does not serve Canadian residents yet (section 1 sources). — [IBKR docs](https://www.interactivebrokers.com/docs/web-api/v1/requirements-limitations/canadian-residents-restricted-from-programmatically-trading-canadian-products), [Questrade API home](https://www.questrade.com/api/home), [Futu OpenAPI](https://openapi.futunn.com/futu-api-doc/en/intro/intro.html), [Alpaca forum](https://forum.alpaca.markets/t/is-the-market-data-subscription-available-in-canada/19519)

### Inferences
- Recommended development path: (1) daily research on Norgate/EODHD data in Python with CAD fee and tick models; (2) record live TSX quotes/trades yourself via IBKR (L1 CAD 9, plus L2 if needed) to build an intraday dataset; (3) paper-trade on IBKR paper with the shared live data subscription; (4) add your own fill/slippage/fee model on top of paper results; (5) test early whether the paper account accepts TSX API orders.
- Most realistic paper-to-live options, in order of likelihood to work for a Canadian-resident retail user: (a) run the same strategy on US-listed securities and Canadian interlisted names through IBKR Canada's API (paper then live, no code changes), accepting that the TSX leg is not available programmatically; (b) for TSX/TSXV/CSE, the model emits signals and you approve and place orders manually (TWS) or via Questrade MCP approvals, which limits frequency to human speed and is unsuited to high-turnover or stop-loss logic that must fire intraday without you; (c) Questrade Flows for simple rule-based exits (including stop/target alerts) but not an ML model; (d) explore non-retail structures (institutional/DEA access, registered firm) with a securities lawyer, which is costly and out of retail budget; (e) wait for a Canadian broker to open a partner API (Questrade partner program) or for Alpaca Canada (no evidence of TSX support).
- The restriction is tied to IIROC/CIRO Dealer Member Rule 3200, and the QuantConnect forum thread discussing IBKR's block is undated (so I cannot say how long it has been enforced). Plan on it persisting, and verify current status with IBKR Canada and Questrade support before committing capital to a plan that depends on it.
- Items that may have changed recently and should be re-checked: Questrade MCP/Flows (launched July 2026, support list already changed), Alpaca Canada (target approval around November 2026), CIRO tick-size changes (November 1, 2027), FINRA PDT replacement (effective June 4, 2026, phase-in to October 2027), TSX fee schedules (July 2 and August 12, 2026), and IBKR's market data table (contains a legacy "April 1, 2020" footnote).

### Gaps
- No direct statement from IBKR Canada or Questrade support on whether paper accounts or practice servers bypass the automated-order restriction.
- Cost and eligibility of non-retail (DEA/institutional) access were not researched.
- TMX Datalinx retail and historical pricing, TSX continuous maker/taker fees, board-lot rules and CSE/TSXV spread statistics remain unretrieved, so the final report should treat microstructure parameters for small caps as assumptions to calibrate from recorded data.
